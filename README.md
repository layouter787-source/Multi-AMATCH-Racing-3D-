# Multi-AMATCH Racing 3D

**Nome oficial do jogo:** Multi-AMATCH Racing 3D

Jogo de corridas arcade 3D para Android, desenvolvido com Godot 4.x.

## Direção do projeto

- Corridas arcade com sensação de velocidade e pistas com identidade própria.
- Multiplayer LAN por Wi-Fi/hotspot, com salas de até 15 jogadores.
- Preparação para multiplayer online por salas e serviços dedicados.
- Exportação Android (APK) através de GitHub Actions.

## Estado

Este repositório foi criado para receber o projeto Godot existente e o workflow de compilação Android. O código-fonte e os recursos 3D ainda precisam ser transferidos para este repositório; por isso, ainda não existe uma compilação APK validada.

## Compilação

A compilação Android será configurada em `.github/workflows/` depois da importação dos ficheiros do projeto.
